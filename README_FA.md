# 🛡️ اسکریپت تست دقیق هر ۴ نوع پروکسی تلگرام (MTProto, SOCKS5, HTTP, WebProxy)

یک ابزار قدرتمند، هوشمند و سبک برای تست واقعی و تخصصی هر **۴ پروتکل رسمی تلگرام**. برخلاف اکثر چکرها که فقط «پینگ خام TCP» می‌گیرند، این ابزار تبادل داده‌های واقعی رمزنگاری‌شده و تونل‌های امن به دیتاسنترهای تلگرام را برقرار می‌کند. اگر پروکسی در این برنامه «سالم» تایید شود، یعنی **۱۰۰٪ در تلگرام کار می‌کند** و روی حالت `Connecting` گیر نخواهد کرد.

![اسکرین شات](images/screenshot_fa.png)

## ✨ پشتیبانی جامع از هر ۴ پروتکل رسمی تلگرام

1. **MTPROTO:** پروکسی‌های استاندارد تلگرام (سکرت ساده ۱۶ بایتی، پیشوند `dd` و فناوری ضد فیلتر **Fake-TLS** با پیشوند `ee` و SNI).
2. **SOCKS5:** پروکسی‌های محبوب SOCKS5 با یا بدون نام‌کاربری و رمز عبور (`tg://socks` و `socks5://`).
3. **HTTP:** پروکسی‌های تونلینگ HTTP/HTTPS با متد CONNECT به سرورهای تلگرام (`tg://http` و `http://user:pass@host:port`).
4. **WEB (WebProxy):** نسل جدید پروکسی‌های وب تلگرام بر بستر وب‌سوکت و TLS با پورت ۴۴۳ (`tg://webproxy` و `https://t.me/webproxy`).

## 🚀 ویژگی‌های کلیدی و پیشرفته

* **📥 دریافت خودکار پروکسی از سابسکریپشن‌ها:** تنها با یک کلیک، جدیدترین پروکسی‌ها از ۱۰ منبع عمومی معتبر و تازه دانلود شده و در کادر ورودی قرار می‌گیرند.
* **⚙️ پنل مدیریت کامل سابسکریپشن‌ها:** امکان مشاهده منابع پیش‌فرض، فعال یا غیرفعال‌سازی هر منبع، افزودن آدرس‌های دلخواه جدید، حذف و بازنشانی (با ذخیره دائمی در مرورگر).
* **⚡ پیش‌چک سریع پورت TCP (اختیاری با چک‌باکس):** امکان غربال سریع پورت‌های بسته در زمان‌های عادی جهت افزایش ۵ تا ۱۰ برابری سرعت تست لیست‌های پرحجم. در زمان اختلال شدید یا فیلترینگ سنگین، می‌توانید این گزینه را غیرفعال کنید تا پروکسی‌های کند به اشتباه رد نشوند.
* **🎯 پروفایل‌های سرعت و شرایط شبکه (Presets):**
  * 🚀 **سریع (Fast):** تاخیر 5s | همزمانی 25 | پیش‌چک فعال (مناسب شرایط اینترنت پایدار).
  * ⚖️ **متعادل (Balanced - پیش‌فرض):** تاخیر 10s | همزمانی 10 | پیش‌چک فعال (مناسب اکثر شرایط).
  * 🐢 **اینترانت / اختلال شدید (National Net):** تاخیر 60s | همزمانی 5 | بدون پیش‌چک (مناسب وضعیت فیلترینگ شدید و اینترانت ملی).
  * 🛠️ **سفارشی (Custom):** تنظیم دستی تاخیر و همزمانی دلخواه توسط کاربر.
* **🚀 اتصال مستقیم بهترین پروکسی به تلگرام ویندوز با یک کلیک:** ارسال بهترین پروکسی (کمترین پینگ) مستقیماً به تلگرام دسکتاپ و باز شدن پنجره اتصال.
* **📋 کپی هوشمند Top N (پیش‌فرض ۱۰ تای برتر):** با فیلد قابل تغییر برای کپی ۵، ۱۰، ۲۰ یا هر تعداد دلخواه از بهترین پروکسی‌ها در کلیپ‌بورد با ساختار تمیز.
* **⏹️ دکمه توقف فوری (Stop):** امکان انصراف و توقف فرآیند بررسی در هر لحظه.
* **💾 خروجی فایل‌های TXT و JSON:** دانلود مستقیم فایل پروکسی‌های سالم به صورت متن تمیز یا ساختار JSON.
* **دیکود خودکار Base64:** شناسایی و دیکود خودکار سابسکریپشن‌های انکودشده.
* **فیلتر هوشمند:** حذف خودکار لینک‌های خراب، سکرت‌های فیک (Spam/Padding) و پورت‌های نامعتبر.
* **دو زبانه و تم مدرن تیره:** پشتیبانی کامل از زبان‌های فارسی و انگلیسی.

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
شما باید **Node.js** را روی سیستم خود داشته باشید. [دانلود Node.js](https://nodejs.org/)

### مراحل اجرا
1. وارد پوشه پروژه شوید:
   ```bash
   cd MTProto-Checker
   ```
2. پکیج‌های لازم را نصب کنید:
   ```bash
   npm install
   ```
3. برنامه را اجرا کنید:
   ```bash
   node app.js
   ```
4. مرورگر شما به طور خودکار باز می‌شود: `http://localhost:3000`

## 📖 راهنمای استفاده

1. **دریافت یا وارد کردن پروکسی:**
   * می‌توانید دکمه **«دریافت پروکسی‌ها از سابسکریپشن‌ها»** را بزنید تا برنامه صدها پروکسی تازه را خودکار دانلود کند.
   * یا متن نامرتب پروکسی‌های خود را در کادر «لیست ورودی» جای‌گذاری کنید.
2. **انتخاب پروفایل یا تنظیم تاخیر:**
   * از منوی بالا یکی از حالت‌های *سریع*، *متعادل* یا *اینترانت/اختلال شدید* را انتخاب کنید.
3. **شروع بررسی:**
   * روی دکمه **«▶️ شروع بررسی دقیق»** کلیک کنید. در صورت تمایل هر لحظه می‌توانید با دکمه **«⏹️ توقف»** فرآیند را قطع کنید.
4. **استفاده از نتایج:**
   * با زدن **«🚀 اتصال بهترین در تلگرام»**، سریع‌ترین پروکسی بلافاصله در تلگرام ویندوز شما باز می‌شود.
   * یا با دکمه **«📋 کپی ۱۰ تای برتر»** یا **«کپی همه»** لیست را بردارید، یا به صورت فایل TXT/JSON ذخیره کنید.

## 🪟 ساخت فایل EXE ویندوز (بدون نیاز به Node.js)

برای تبدیل این ابزار به یک فایل مستقل `.exe` که در هر سیستم ویندوزی بدون نصب Node.js اجرا شود:

```bash
npm run build:win
```
فایل اجرایی در پوشه `dist/mtproto-checker.exe` ساخته خواهد شد. همچنین با پوش تگ روی گیت‌هاب، اکشن گیت‌هاب فایل را به صورت خودکار می‌سازد.
